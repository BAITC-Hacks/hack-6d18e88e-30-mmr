# Catalog

**Owner**: Developer 2 (or Marketplace Lead)

### Responsibilities:
- Public catalog of all confirmed/published tasks
- Search by keywords
- Filters by topic/industry and readiness level
- Sorting by rating score
- Task details modal/view

### Critical Rules:
- Do not redefine Task. Use `src/types/task.ts`.
- Ensure all tasks are visible to all teams (open catalog rule).
