# Письма AI Sana

Два HTML-файла содержат **шаблоны для Supabase**, а не уже отправленные письма:

| Раздел Authentication → Emails → Templates | Subject | Файл Body |
|---|---|---|
| Confirm sign up | Подтвердите почту в AI Sana | `confirmation.html` |
| Reset password | Восстановление доступа к AI Sana | `recovery.html` |

Вставьте весь HTML в Body соответствующего шаблона и сохраните. Не заменяйте `{{ .SiteURL }}` и `{{ .TokenHash }}` вручную: Supabase подставляет значения при отправке. Для локальной разработки Site URL должен быть `http://localhost:5173` **без завершающего `/`**. Шаблоны ведут на React, где выполняется проверка одноразового токена. В production установите HTTPS-адрес приложения.

Готовые статические образцы находятся в `preview/`: их можно открыть браузером. Ссылки в образцах ведут на `https://example.invalid`, токены демонстрационные; вход или восстановление через них не работают. **В панель Supabase вставляйте основные файлы, не файлы из preview.**

Дизайн согласован со страницей аккаунта: глубокая зелёная брендовая панель, мятный акцент, светлая карточка, крупная кнопка и отдельный блок срока действия. Табличная вёрстка с inline CSS не зависит от внешних шрифтов, изображений, JavaScript или CSS приложения. Декоративные градиенты имеют сплошной фон для почтовых клиентов без их поддержки. Размытие в письмах не используется: Gmail и Outlook поддерживают его непоследовательно. Реальная отрисовка может отличаться между почтовыми клиентами.

Локальный Python backend использует тот же стиль в `backend/services/email_templates.py`. Красивое HTML-письмо отправляется вместе с текстовой версией при `AUTH_MAIL_FORMAT=html`; режим `text` сохраняет простые текстовые письма. Изменение этих файлов не устанавливает шаблоны в облачный Supabase автоматически.

Срок действия не зашит в текст письма: он задаётся в настройках Auth. Повторно использованная или просроченная ссылка требует нового письма. Шаблон не содержит пароля. Для новостной рассылки используется отдельная очередь FastAPI, а не шаблон восстановления.

Детальная настройка и проверка: [SUPABASE_SETUP.md](../../docs/SUPABASE_SETUP.md).
